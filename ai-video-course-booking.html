The Framework

Six techniques. One consistent pipeline.

Not a list of prompt tricks — the actual system used to take an AI video project from a rough idea to a deliverable a real client signed off on.
01Consistency
Character Reference Sheet
An 8-section continuity document that locks a character's identity before you generate a single shot — so they don't quietly turn into a different person by shot four.
hair, face structure, build, wardrobe, age, distinguishing features, expression range, camera-facing angle...
02Consistency
Location & Props Sheet
The companion technique — locks the setting and recurring objects the same way the character sheet locks a face, so your world doesn't shift between cuts either.
time of day, weather, recurring objects, materials, color palette, camera height reference...
03Coherence
The Grid Technique
Overlaying a grid on a character's face for frame-to-frame facial coherence — a small trick that fixes one of the most common AI-video tells.
grid overlay reference → facial landmark lock → frame-to-frame comparison
04Efficiency
Cherry-Pick, Don't Accept
Download every variant a generation gives you, keep only the best segments from each, and re-edit — instead of accepting one full generation as final.
generate 4-6 variants → isolate best 2-3s segments → reassemble in edit
05Efficiency
Video-to-Video Iteration
When a generation is close but not right, iterate on the actual video instead of burning tokens on a full fresh text-to-video generation.
source clip + targeted prompt delta → video-to-video pass → compare
06Direction
Prompt Simplification
Replace proper nouns, brand names, and place names with plain visual descriptions the model can actually interpret — jargon it doesn't recognize is jargon it ignores.
"Terra Solida paving" → "light beige permeable stone pathway"
Tool Selection

Knowing which tool matters as much as the prompt.

Part of the course is a living comparison of the current best AI video tools — not theory, findings from real production work.
Seedance
Higher overall generation quality across most shot types — the default choice for the bulk of a sequence.
Kling
Stronger specifically at video openings — worth reaching for on the first few seconds of a sequence even when Seedance carries the rest.
