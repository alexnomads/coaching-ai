Scegli il sistema operativo: Ubuntu

Hostinger lo chiede durante l'acquisto

Il tuo server ha bisogno di un sistema operativo, proprio come il tuo portatile. Hostinger te ne proporrà diversi. Scegli Ubuntu 24.04 LTS (o 22.04 LTS).

  • Ubuntu ✅ — la scelta più diffusa per i server, con più tutorial e aiuto online.
  • Debian — va bene anche questo, molto simile a Ubuntu.
  • Windows ❌ — disponibile, ma sconsigliato: costa di più, usa più memoria e tutte le istruzioni di OpenClaw sono scritte per Linux.
Niente paura
Non devi "sapere Linux". Scriverai solo una manciata di comandi, e sono tutti in questa guida, pronti da copiare. Funziona allo stesso modo sia che il tuo computer sia un Mac, sia un PC Windows.

Collegati al tuo server (SSH)

Scegli il modo adatto al tuo computer

SSH è come una telefonata sicura al tuo server: scrivi i comandi sul tuo computer e vengono eseguiti sul server. Scegli uno di questi tre modi:

Il più facile

🌐 Nel browser

Qualsiasi computer. Nell'hPanel di Hostinger, apri il tuo VPS e clicca Browser terminal. Niente da installare.

Integrato

🍎 Mac o Linux

Apri l'app Terminale (Mac: Applicazioni → Utility → Terminale) e scrivi il comando qui sotto.

Integrato

🪟 Windows

Apri Windows Terminal o PowerShell (premi Start e scrivi "terminal") e scrivi il comando qui sotto. Funziona anche PuTTY.

Collegati (Mac · Linux · Windows Terminal)
ssh root@YOUR_SERVER_IP
# Esempio: ssh root@185.199.110.153
# Ti chiederà la password → incolla quella di Hostinger.
# NON vedrai i caratteri mentre scrivi la password. È normale!
# Solo la prima volta: scrivi "yes" se ti chiede di fidarti del server.
Concetto chiave
Una volta collegato, tutto quello che scrivi viene eseguito sul server, non sul tuo computer. Vedrai il prompt cambiare in qualcosa come root@srv123:~# — così sai di essere "dentro".
Verifica veloce — sei dentro?
whoami      # dovrebbe stampare: root
free -h     # quanta memoria ha il server
df -h       # quanto spazio su disco è libero
✓
Fatto quando: whoami stampa root.
Passo 2 di 4

Installa OpenClaw

OpenClaw è un software gratuito e open-source che trasforma il tuo server in un agente IA a cui puoi scrivere. Lo installeremo con Docker — il modo più sicuro e semplice.

Dove scrivo questi comandi?
Nel terminale collegato al tuo server (Passo 1). Non in un nuovo terminale sul tuo computer. Se usi il Browser terminal di Hostinger, sei già nel posto giusto.
1

Cos'è Docker e perché usarlo?

Docker impacchetta un programma insieme a tutto ciò che gli serve in una scatola sigillata chiamata container.

  • Senza Docker: installi a mano tanti pezzi separati e speri che funzionino insieme.
  • Con Docker: un solo comando, e OpenClaw parte con tutto incluso.
  • Aggiornare significa solo scaricare la scatola più nuova.
  • Se qualcosa si rompe, butti la scatola e ne avvii una nuova — il resto del server resta intatto.
In parole semplici
Docker funziona come un'app sul telefono: la installi con un tocco, porta con sé tutto ciò che le serve e, se fa i capricci, la cancelli e la reinstalli — senza toccare nient'altro.
2

3

Metodo 2 — Installa con i comandi

Se OpenClaw non è nel catalogo, o preferisci il terminale

2a. Installa Docker (una volta sola):

Installa Docker
curl -fsSL https://get.docker.com | sh
docker --version   # dovrebbe stampare qualcosa come: Docker version 27.x

2b. Avvia OpenClaw:

Avvia OpenClaw
docker run -d \
  --name openclaw \
  --restart unless-stopped \
  -p 18789:18789 \
  -v openclaw-data:/root/.openclaw \
  openclaw/openclaw:latest
Cosa significa ogni parte
docker run avvia un container · -d gira in background · --name openclaw gli dà un nome semplice · --restart unless-stopped si riavvia da solo dopo un crash o un riavvio · -p 18789:18789 apre la porta 18789 per la dashboard · -v openclaw-data:… tiene al sicuro le impostazioni su disco · openclaw/openclaw:latest la versione più recente di OpenClaw

2c. Controlla che stia girando:

Controlla
docker ps
# Cerca "openclaw" con STATUS "Up ..." → tutto ok.
# Se dice "Exited", guarda cosa è andato storto con:
docker logs openclaw
✓
Fatto quando: docker ps mostra openclaw con stato Up.
4

Apri la dashboard (Control UI)

Porta predefinita 18789 — dalla documentazione ufficiale di OpenClaw

OpenClaw ha una dashboard web. Sul tuo computer, apri un browser qualsiasi e vai su:

Barra degli indirizzi
http://YOUR_SERVER_IP:18789

Ti chiederà un gateway token (una password per la dashboard). Trovalo sul server:

Trova il gateway token
docker logs openclaw 2>&1 | grep -i token
La pagina non si carica?
La porta 18789 potrebbe essere chiusa dal firewall. Aprila in hPanel → VPS → Firewall → Add rule (TCP, porta 18789, Accept) — oppure sul server esegui ufw allow 18789/tcp. Per più sicurezza, consenti solo il tuo indirizzo IP.
✓
Fatto quando: vedi la dashboard di OpenClaw nel browser.
5

Conosci il file di impostazioni: openclaw.json

~/.openclaw/openclaw.json

Tutte le impostazioni di OpenClaw stanno in un solo file. Lo completerai nei prossimi due passi. Ecco cosa fa ogni parte:

openclaw.json — spiegato
{
  // 1) IL CERVELLO — quale servizio IA usare (Passo 3)
  "providers": {
    "venice": {
      "apiKey": "vnc-...",                        // la tua chiave segreta Venice
      "defaultModel": "venice/deepseek-v4-flash"  // il modello IA da usare
    }
  },

  // 2) LE LINEE TELEFONICHE — come parli con lui (Passo 4)
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456:ABC-...",               // da BotFather
      "accounts": {
        "+15551234567": { "role": "admin", "name": "Alex" }  // chi può usarlo
      }
    },
    "discord": {
      "enabled": true,
      "token": "MTIz...",                         // dal Discord Developer Portal
      "applicationId": "123456789...",
      "guilds": { "YOUR_SERVER_ID": { "channels": { "CHANNEL_ID": {} } } }
    }
  },

  // 3) BUONE MANIERE — quando deve rispondere
  "messages": {
    "directMessage": { "autoApprove": true },     // risponde sempre nelle chat private
    "groupChat": { "requireMention": true }       // nei gruppi, solo quando @menzionato
  }
}
Regola d'oro
Dopo ogni modifica a questo file, riavvia OpenClaw perché legga le nuove impostazioni: docker restart openclaw

nano è un semplice editor di testo dentro il terminale. Usa le frecce per muoverti (il mouse non funziona), scrivi normalmente, poi Ctrl+O + Invio per salvare e Ctrl+X per uscire. Anche su Mac è Ctrl, non Cmd.

Crea un bot Telegram

Dal telefono · ~3 minuti
  1. In Telegram, cerca @BotFather (il bot ufficiale con la spunta blu) e aprilo.
  2. Invia /newbot.
  3. Scegli un nome visualizzato, per esempio Assistente di Alex.
  4. Scegli uno username che finisca con "bot", per esempio alex_assistant_bot.
  5. BotFather risponde con il tuo bot token → copialo.
  6. Facoltativo, per le chat di gruppo: invia /setprivacy, scegli il tuo bot, poi Disable.
Aggiungilo a openclaw.json

// Usa il tuo numero con prefisso internazionale. Poi: docker restart openclaw
2

Crea un bot Discord

Da computer · ~8 minuti
  1. Vai su discord.com/developers/applications e clicca New Application (chiamala "Assistente di Alex").
  2. Nel menu a sinistra, apri Bot → clicca Reset Token → copia il token.
  3. Nella stessa pagina, sotto Privileged Gateway Intents, attiva Message Content Intent e Server Members Intent.
  4. Apri OAuth2 → URL Generator. Spunta bot, poi i permessi Send Messages, Read Message History, Embed Links.
  5. Copia il link generato, aprilo nel browser e invita il bot nel tuo server Discord.
Perché Discord funziona benissimo
Crea un canale per argomento — #general per domande veloci, #reports per i riassunti, #deadlines per seguire le scadenze, #email per scrivere messaggi. Il tuo agente tiene ogni conversazione separata.
Aggiungilo a openclaw.json
