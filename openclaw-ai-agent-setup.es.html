Elige el sistema operativo: Ubuntu

Hostinger te lo pregunta al pagar

Tu servidor necesita un sistema operativo, igual que tu portátil. Hostinger te ofrecerá varios. Elige Ubuntu 24.04 LTS (o 22.04 LTS).

Tranquilo
No necesitas "saber Linux". Solo escribirás unos pocos comandos, y todos están en esta guía, listos para copiar. Funciona igual tanto si tu ordenador es un Mac como un PC con Windows.

Conéctate a tu servidor (SSH)

Elige la forma que corresponde a tu ordenador

SSH es como una llamada telefónica segura a tu servidor: escribes comandos en tu ordenador y se ejecutan en el servidor. Elige una de estas tres formas:

La más fácil

🌐 En el navegador

Cualquier ordenador. En el hPanel de Hostinger, abre tu VPS y haz clic en Browser terminal. Nada que instalar.

Integrado

🍎 Mac o Linux

Abre la app Terminal (Mac: Aplicaciones → Utilidades → Terminal) y escribe el comando de abajo.

Integrado

🪟 Windows

Abre Windows Terminal o PowerShell (pulsa Inicio y escribe "terminal") y escribe el comando de abajo. PuTTY también funciona.

Conectar (Mac · Linux · Windows Terminal)
ssh root@YOUR_SERVER_IP
# Ejemplo: ssh root@185.199.110.153
# Te pedirá la contraseña → pega la de Hostinger.
# NO verás los caracteres mientras la escribes. ¡Es normal!
# Solo la primera vez: escribe "yes" si te pide confiar en el servidor.
Idea clave
Una vez conectado, todo lo que escribes se ejecuta en el servidor, no en tu ordenador. Verás que el prompt cambia a algo como root@srv123:~# — así sabes que estás "dentro".
Comprobación rápida — ¿estás dentro?
whoami      # debería mostrar: root
free -h     # cuánta memoria tiene el servidor
df -h       # cuánto espacio en disco queda libre
✓
Listo cuando: whoami muestra root.
Paso 2 de 4

Instala OpenClaw

OpenClaw es un software gratuito y de código abierto que convierte tu servidor en un agente de IA al que puedes escribir. Lo instalaremos con Docker — la forma más segura y sencilla.

¿Dónde escribo estos comandos?
En el terminal que está conectado a tu servidor (Paso 1). No en un terminal nuevo de tu ordenador. Si usas el Browser terminal de Hostinger, ya estás en el sitio correcto.
1

¿Qué es Docker y por qué usarlo?

Docker empaqueta un programa junto con todo lo que necesita en una caja sellada llamada contenedor.

  • Sin Docker: instalas a mano muchas piezas por separado y esperas que funcionen juntas.
  • Con Docker: un solo comando y OpenClaw arranca con todo incluido.
  • Actualizar es solo descargar la caja más nueva.
  • Si algo se rompe, tiras la caja y empiezas una nueva — el resto del servidor queda intacto.
En pocas palabras
Docker funciona como una app del móvil: la instalas con un toque, trae todo lo que necesita y, si da problemas, la borras y la reinstalas — sin afectar a nada más.
2

  2. Abre el Catálogo y busca OpenClaw.
  3. Haz clic en Deploy — los ajustes vienen rellenados.

✓
Listo cuando: OpenClaw aparece como running. Puedes saltarte el Método 2 e ir a "Abre el panel".
3

Método 2 — Instalar con comandos

Si OpenClaw no está en el catálogo, o prefieres el terminal

2a. Instala Docker (una sola vez):

Instalar Docker
curl -fsSL https://get.docker.com | sh
docker --version   # debería mostrar algo como: Docker version 27.x

2b. Arranca OpenClaw:

Ejecutar OpenClaw
docker run -d \
  --name openclaw \
  --restart unless-stopped \
  -p 18789:18789 \
  -v openclaw-data:/root/.openclaw \
  openclaw/openclaw:latest
Qué significa cada parte
docker run arranca un contenedor · -d se ejecuta en segundo plano · --name openclaw le da un nombre fácil · --restart unless-stopped se reinicia solo tras un fallo o reinicio · -p 18789:18789 abre la puerta 18789 para el panel · -v openclaw-data:… guarda tus ajustes a salvo en el disco · openclaw/openclaw:latest la versión más reciente de OpenClaw

2c. Comprueba que está funcionando:

Comprobar
docker ps
# Busca "openclaw" con STATUS "Up ..." → todo bien.
# Si dice "Exited", mira qué ha fallado con:
docker logs openclaw
✓
Listo cuando: docker ps muestra openclaw con estado Up.
4

Abre el panel (Control UI)

Puerto por defecto 18789 — según la documentación oficial de OpenClaw

OpenClaw tiene un panel web. En tu propio ordenador, abre cualquier navegador y ve a:

Barra de direcciones
http://YOUR_SERVER_IP:18789

Te pedirá un gateway token (una contraseña para el panel). Búscalo en el servidor:

Encontrar el gateway token
docker logs openclaw 2>&1 | grep -i token
¿La página no carga?
Puede que el firewall tenga cerrada la puerta 18789. Ábrela en hPanel → VPS → Firewall → Add rule (TCP, puerto 18789, Accept) — o en el servidor ejecuta ufw allow 18789/tcp. Para más seguridad, permite solo tu propia dirección IP.
✓
Listo cuando: ves el panel de OpenClaw en tu navegador.
5

Conoce el archivo de ajustes: openclaw.json

~/.openclaw/openclaw.json

Todos los ajustes de OpenClaw están en un solo archivo. Lo irás completando en los dos próximos pasos. Esto es lo que hace cada parte:

openclaw.json — explicado
{
  // 1) EL CEREBRO — qué servicio de IA usar (Paso 3)
  "providers": {
    "venice": {
      "apiKey": "vnc-...",                        // tu clave secreta de Venice
      "defaultModel": "venice/deepseek-v4-flash"  // el modelo de IA a usar
    }
  },

  // 2) LAS LÍNEAS DE TELÉFONO — cómo hablas con él (Paso 4)
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456:ABC-...",               // de BotFather
      "accounts": {
        "+15551234567": { "role": "admin", "name": "Alex" }  // quién puede usarlo
      }
    },
    "discord": {
      "enabled": true,
      "token": "MTIz...",                         // del Discord Developer Portal
      "applicationId": "123456789...",
      "guilds": { "YOUR_SERVER_ID": { "channels": { "CHANNEL_ID": {} } } }
    }
  },

  // 3) MODALES — cuándo debe responder
  "messages": {
    "directMessage": { "autoApprove": true },     // responde siempre en chats privados
    "groupChat": { "requireMention": true }       // en grupos, solo cuando lo @mencionan
  }
}
Regla de oro
Después de cualquier cambio en este archivo, reinicia OpenClaw para que lea los nuevos ajustes: docker restart openclaw

Conecta la clave a OpenClaw

Elige una de las dos formas

Forma 1 — el asistente de configuración (la más fácil):

Ejecutar el asistente
docker exec -it openclaw openclaw onboard
# En el asistente:
# 1. Elige "Venice AI" en la lista de proveedores
# 2. Pega tu clave (vnc-...)
# 3. Elige el modelo por defecto (empieza con deepseek-v4-flash)
# 4. Confirma

Forma 2 — editar el archivo de ajustes a mano:

Editar openclaw.json
nano /root/.openclaw/openclaw.json
# Busca "providers" y pon:
"providers": {
  "venice": {
    "apiKey": "vnc-YOUR-KEY-HERE",
    "defaultModel": "venice/deepseek-v4-flash"
  }
}
# Guardar: Ctrl+O y luego Enter · Salir: Ctrl+X
docker restart openclaw
Sobre el editor nano
nano es un editor de texto sencillo dentro del terminal. Usa las flechas para moverte (el ratón no funciona), escribe normalmente y luego Ctrl+O + Enter para guardar y Ctrl+X para salir. En Mac también es Ctrl, no Cmd.

Crea un bot de Telegram

En el móvil · ~3 minutos
  1. En Telegram, busca @BotFather (el bot oficial con la marca azul) y ábrelo.
  2. Envía /newbot.
  3. Elige un nombre visible, por ejemplo Asistente de Alex.
  4. Elige un nombre de usuario que termine en "bot", por ejemplo alex_assistant_bot.
  5. BotFather responde con tu bot token → cópialo.
  6. Opcional, para chats de grupo: envía /setprivacy, elige tu bot y luego Disable.
Añádelo a openclaw.json
"telegram": {
  "enabled": true,
  "botToken": "PASTE-THE-BOTFATHER-TOKEN",
  "accounts": {
    "+15551234567": { "role": "admin", "name": "Alex" }
  }
}
// "accounts" es tu lista de invitados: solo estos números pueden usar el bot.
// Usa tu propio número con prefijo de país. Después: docker restart openclaw
2

Crea un bot de Discord

En un ordenador · ~8 minutos
  1. Ve a discord.com/developers/applications y haz clic en New Application (llámala "Asistente de Alex").
  2. En el menú de la izquierda, abre Bot → haz clic en Reset Token → copia el token.
  3. En la misma página, en Privileged Gateway Intents, activa Message Content Intent y Server Members Intent.
  4. Abre OAuth2 → URL Generator. Marca bot y luego los permisos Send Messages, Read Message History, Embed Links.
  5. Copia el enlace generado, ábrelo en el navegador e invita al bot a tu servidor de Discord.
Por qué Discord brilla
Crea un canal por tema — #general para preguntas rápidas, #reports para resúmenes, #deadlines para seguir fechas límite, #email para redactar mensajes. Tu agente mantiene cada conversación por separado.
Añádelo a openclaw.json
"discord": {
  "enabled": true,
  "token": "PASTE-THE-DEVELOPER-PORTAL-TOKEN",
  "applicationId": "YOUR-APPLICATION-ID",
  "guilds": {
    "YOUR_SERVER_ID": {
      "channels": { "GENERAL_CHANNEL_ID": {}, "REPORTS_CHANNEL_ID": {} }
    }
  }
}
// El bot solo responde en los canales listados aquí.
// Para copiar IDs: Ajustes de Discord → Avanzado → activa el Modo desarrollador,
// luego clic derecho en un servidor o canal → Copiar ID. Después: docker restart openclaw
