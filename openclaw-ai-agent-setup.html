Connect to your server (SSH)

Pick the way that matches your computer

SSH is like a secure phone call to your server: you type commands on your computer, and they run on the server. Choose one of these three ways:

Easiest

🌐 In your browser

Any computer. In Hostinger's hPanel, open your VPS and click Browser terminal. Nothing to install.

Built in

🍎 Mac or Linux

Open the Terminal app (Mac: Applications → Utilities → Terminal) and type the command below.

Built in

🪟 Windows

Open Windows Terminal or PowerShell (press Start, type "terminal") and type the command below. PuTTY also works.

Connect (Mac · Linux · Windows Terminal)
ssh root@YOUR_SERVER_IP
# Example: ssh root@185.199.110.153
# It will ask for your password → paste the one from Hostinger.
# You WON'T see the characters while typing the password. That's normal!
# First time only: type "yes" if asked to trust the server.
Key idea
Once connected, everything you type runs on the server, not on your computer. You'll see your prompt change to something like root@srv123:~# — that's how you know you're "inside".
Quick check — are you in?
whoami      # should print: root
free -h     # how much memory the server has
df -h       # how much disk space is free
✓
Done when: whoami prints root.

Install OpenClaw

OpenClaw is free, open-source software that turns your server into an AI agent you can message. We'll install it with Docker — the safest and simplest way.

Where do I type these commands?
In the terminal that's connected to your server (Step 1). Not in a new terminal on your own computer. If you're using Hostinger's Browser terminal, you're already in the right place.
1

What is Docker, and why use it?

Docker packs a program together with everything it needs into a sealed box called a container.

  • Without Docker: you install many separate pieces by hand and hope they work together.
  • With Docker: one command, and OpenClaw starts with everything included.
  • Updating is just downloading the newer box.
  • If something breaks, you throw the box away and start a fresh one — the rest of your server stays untouched.
In plain English
Docker works like an app on your phone: you install it in one tap, it brings everything it needs, and if it misbehaves you delete it and reinstall — without affecting anything else.

Method 2 — Install with commands

If OpenClaw isn't in the catalog, or you prefer the terminal

2a. Install Docker (one-time):

Install Docker
curl -fsSL https://get.docker.com | sh
docker --version   # should print something like: Docker version 27.x

2b. Start OpenClaw:

Run OpenClaw
docker run -d \
  --name openclaw \
  --restart unless-stopped \
  -p 18789:18789 \
  -v openclaw-data:/root/.openclaw \
  openclaw/openclaw:latest
What each part means
docker run start a container · -d run in the background · --name openclaw give it an easy name · --restart unless-stopped restart automatically after a crash or reboot · -p 18789:18789 open door 18789 for the dashboard · -v openclaw-data:… keep your settings safe on disk · openclaw/openclaw:latest the newest version of OpenClaw

2c. Check it's running:

Check
docker ps
# Look for "openclaw" with STATUS "Up ..." → all good.
# If it says "Exited", see what went wrong with:
docker logs openclaw
✓
Done when: docker ps shows openclaw with status Up.

Open the dashboard (Control UI)

Default port 18789 — from the official OpenClaw docs

It will ask for a gateway token (a password for the dashboard). Find it on the server:

Find the gateway token
docker logs openclaw 2>&1 | grep -i token
Page won't load?
Door 18789 may be closed by the firewall. Open it in hPanel → VPS → Firewall → Add rule (TCP, port 18789, Accept) — or on the server run ufw allow 18789/tcp. For extra safety, allow only your own IP address.

5

Meet the settings file: openclaw.json

~/.openclaw/openclaw.json

All of OpenClaw's settings live in one file. You'll fill it in over the next two steps. Here's what each part does:

openclaw.json — explained
{
  // 1) THE BRAIN — which AI service to use (Step 3)
  "providers": {
    "venice": {
      "apiKey": "vnc-...",                        // your secret Venice key
      "defaultModel": "venice/deepseek-v4-flash"  // the AI model to use
    }
  },

  // 2) THE PHONE LINES — how you talk to it (Step 4)
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456:ABC-...",               // from BotFather
      "accounts": {
        "+15551234567": { "role": "admin", "name": "Alex" }  // who is allowed to use it
      }
    },
    "discord": {
      "enabled": true,
      "token": "MTIz...",                         // from Discord Developer Portal
      "applicationId": "123456789...",
      "guilds": { "YOUR_SERVER_ID": { "channels": { "CHANNEL_ID": {} } } }
    }
  },

  // 3) MANNERS — when it should reply
  "messages": {
    "directMessage": { "autoApprove": true },     // always reply in private chats
    "groupChat": { "requireMention": true }       // in groups, only when @mentioned
  }
}
Golden rule
After any change to this file, restart OpenClaw so it reads the new settings: docker restart openclaw

Plug the key into OpenClaw

Choose one of the two ways

Way 1 — the setup wizard (easiest):

Run the wizard

nano /root/.openclaw/openclaw.json

About the nano editor
nano is a simple text editor inside the terminal. Use the arrow keys to move (the mouse won't work), type normally, then Ctrl+O + Enter to save and Ctrl+X to exit. On Mac it's also Ctrl, not Cmd.

Create a Telegram bot

On your phone · ~3 minutes
  1. In Telegram, search for @BotFather (the official bot with a blue check) and open it.
  2. Send /newbot.
  3. Choose a display name, e.g. Alex Assistant.
  4. Choose a username ending in "bot", e.g. alex_assistant_bot.
  5. BotFather replies with your bot token → copy it.
  6. Optional, for group chats: send /setprivacy, choose your bot, then Disable.
Add it to openclaw.json
"telegram": {
  "enabled": true,
  "botToken": "PASTE-THE-BOTFATHER-TOKEN",
  "accounts": {
    "+15551234567": { "role": "admin", "name": "Alex" }
  }
}
// "accounts" is your guest list: only these phone numbers can use the bot.
// Use your own number with country code. Then: docker restart openclaw
2

Create a Discord bot

On a computer · ~8 minutes
  1. Go to discord.com/developers/applications and click New Application (name it "Alex Assistant").
  2. In the left menu, open Bot → click Reset Token → copy the token.
  3. On the same page, under Privileged Gateway Intents, switch on Message Content Intent and Server Members Intent.
  4. Open OAuth2 → URL Generator. Tick bot, then the permissions Send Messages, Read Message History, Embed Links.
  5. Copy the generated link, open it in your browser and invite the bot to your Discord server.
Why Discord shines
Create one channel per topic — #general for quick questions, #reports for summaries, #deadlines to track due dates, #email for drafting messages. Your agent keeps each conversation separate.
Add it to openclaw.json
"discord": {
  "enabled": true,
  "token": "PASTE-THE-DEVELOPER-PORTAL-TOKEN",
  "applicationId": "YOUR-APPLICATION-ID",
  "guilds": {
    "YOUR_SERVER_ID": {
      "channels": { "GENERAL_CHANNEL_ID": {}, "REPORTS_CHANNEL_ID": {} }
    }
  }
}
// The bot only answers in the channels listed here.
// To copy IDs: Discord Settings → Advanced → turn on Developer Mode,
// then right-click a server or channel → Copy ID. Then: docker restart openclaw
